# Midjourney

> Discord 生态的艺术向 AI 生图工具。

## 摘要

Midjourney 以艺术质量和美学见长，但**产品一致性**较弱，不适合作为本项目主力。在 `engine_config.yaml` 中列为备选引擎。

## 关键能力

| 能力 | 一致性影响 |
|-----|-----------|
| `--cref` / character reference | 人物一致性好，产品一致性有限 |
| `--sref` style reference | 风格统一，非产品形态 |
| 高美学质量 | 适合氛围场景（scene_07） |

## 本项目定位

- **备选引擎**：主引擎失败时 fallback
- **适用场景**：[[场景模板体系]] 中的氛围/品牌故事类
- **不适用**：需要严格产品形态一致的主图/详情图
