# Temu 核价机制与差异化破局策略

> 来源：抖音「高速开飞机（C.E）」视频分析 + 实操验证
> 整理日期：2026-07-04

## 核心认知

**平台核价低，很多时候不是因为你报价高，而是平台把你的商品识别成了"已有同款"，然后拿你去和最低价同类商品比较。**
真正的破局点不是"怎么过核价"，而是**"如何不再成为最低价同款"**。

---

## 一、核价的底层逻辑

### 被低价匹配的链路
```
采集同款 → 直接复制标题/图片/SKU
         → 平台识别为高度同质商品
         → 进入已有同款比价池
         → 价格透明 → 平台按低价参考压缩空间
         → 卖家利润越来越薄
```

### 正确方向
```
找到需求 → 重新定义使用场景 → 重做标题与视觉
         → 重组 SKU/套装 → 微改产品
         → 降低物流或管理成本 → 增加真实资质与价值证据
         → 形成新的商品价值结构 → 减少与最低价同款的直接比较
```

---

## 二、四大差异化层级（按优先级）

### 1. 标题差异化（最重要、成本最低）
不要机械换同义词，要改变商品的价值表达。

| 写法 | 示例 |
|------|------|
| ❌ 普通 | Cleaning Cloth |
| ✅ 场景化 | Reusable Juicer Cleaning Cloth for Kitchen Appliance Care |
| ✅ 垂直化 | Handcrafted-Style Reusable Cleaning Cloth for Juicers and Small Kitchen Appliances |

核心变化：用户对象、使用场景、搜索意图、功能解释、商品价值感。

### 2. 主图差异化
不要使用供应链全网流通的标准公版图。
重新构建：拍摄角度、产品比例、使用场景、功能演示、尺寸表达、材质细节、套装构成、对比逻辑。

> 商品从"卖一块布"变成"解决某个具体清洁问题的工具"。

### 3. 类目与场景差异化
同一产品不一定只有一种卖法。例如清洁布可定义为：
- 厨房清洁用品（默认池）
- 榨汁机清洁（垂直池，竞争小）
- 咖啡机维护（高客单价池）
- 露营餐具清洁（户外人群池）

本质：**重新回答"这个产品到底为谁、在什么场景下、解决什么问题"**。

### 4. SKU 重组
不要仅 Red/Blue/Black。围绕以下维度重组：
- 数量（1/3/5 Pack → Starter/Family/Heavy-Use Set）
- 尺寸、材质、包装、配件、使用对象、场景、礼物对象、个性化选项

## 三、Temu 平台专项策略

### Temu 核价特点
- 比价算法对标题关键词匹配极度敏感
- 图片识别强：主图风格高度相似会被直接放入同一比价池
- 价格敏感型用户平台：规格/数量优势比品牌溢价更有效
- 3:4 竖图为主，1350px 以上，牛皮癣文字容忍度低

### Temu 差异化重心
1. **规格重组**：重做套装组合（不是单纯加价，而是改变比较单位）
2. **场景重构**：在 Temu 搜索框架内找竞争小的场景词
3. **物流结构优化**：体积/重量降低 → 平台物流费低 → 核价空间大
4. **真实价值证据**：检测报告、实拍图、视频

### 举例
```
普通木质产品：
  1 个木牌
差异化：
  门牌套装 / 婚礼桌牌套装 / 宠物纪念套装 / 家庭姓名牌 / 儿童房成长牌
```

## 四、产品微创新（最稳定差异）

不需要新生产线或大规模开模的低成本微改：

| 类别 | 方案 |
|------|------|
| 结构 | 可折叠、可伸缩、减少体积、降低重量 |
| 配件 | 增加挂孔、收纳结构、替换件、配件 |
| 包装 | 改包装尺寸、礼盒、模块化 |
| 定制 | 刻字区域、UV 定制区域 |
| 组合 | 改颜色组合、多件套 |

### 双重收益
- **商品差异**：更难被消费者直接拿去和最低价裸同款比较
- **成本结构优化**：体积↓ → 头程↓ → 仓储↓ → 尾程↓ → 退货损失↓

---

## 五、资质壁垒（必须真实）

可建立差异化门槛的资质（需真实、报告型号与实际商品一致）：
- FDA 相关合规（食品接触材料）
- CE / RoHS / REACH
- CPSIA / ASTM（儿童用品）
- FSC（环保材质）
- OEKO-TEX（纺织品）

**绝对禁止**：
- 无报告却写认证 → 封店风险
- 借用其他工厂报告 → 侵权
- "tested"冒充"certified" → 下架
- 报告型号与商品不一致 → 核价/审核双重风险

## 六、标准 SOP：从 1688 采集后的改造步骤

### Step 1 — 成本底线
先算清：采购+国内运费+包装+头程+尾程+平台费用+支付费用+广告+退款损耗+破损+税费+目标利润
**不要先看平台核多少再决定赚不赚钱。**

### Step 2 — 竞品池构建
最少找 50 个：10 最低价款 + 10 销量款 + 10 高价款 + 10 新款 + 10 差异化款。
核心问题：**为什么高价款还能卖？** 这比研究最低价重要得多。

### Step 3 — 选至少 3 个差异化轴
从 14 个维度中选：人群/场景/功能/材质/尺寸/数量/配件/包装/颜色/情绪/礼物对象/个性化/资质/物流体积
**至少做 3 个，不要只改图片。**

### Step 4 — 找 3-5 家供应商问对问题
不只是「最低多少钱」，而是：
- 能不能改尺寸/换材质/增加挂孔/折叠/减少体积/换包装/加配件？
- 能不能激光雕刻/UV/做小批量？有无检测报告？

### Step 5 — 重建 Listing
重新做：标题+主图+副图+SKU+属性+描述+场景+视频+包装表达+价值证明

### Step 6 — A/B 三版本测试
```
A：基础低价版
B：差异场景版
C：高价值套装版
```
对比：点击率/转化率/收藏/加购/退款/毛利/广告效率/核价结果

---

## 七、容易踩的坑

- ❌ 把差异化理解成欺骗系统（虚假描述/错放类目）→ 合规风险
- ❌ 只改 AI 背景不改商品价值 → 不算真正差异化
- ❌ 标题堆关键词 → 关键词越多不代表价值越高
- ❌ 为了高核价加无意义成本 → 成本↑退货↑转化↓

差异化必须围绕真实需求。

我们的出图 Agent 正好实现这套差异化的**视觉/标题/SKU 层**：
- `scene_matcher.py` 做场景差异化（用户不选默认池，重新定义使用场景）

- `listing_rules.py` 做平台标题优化
- 多引擎调度可按 Temu 3:4 竖图规格自动适配
- `subject_lock.py` 解决产品一致性（非公版图问题）
