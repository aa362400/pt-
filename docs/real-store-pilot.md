# 真实店铺试点

状态：`NOT_STARTED`

## 目标样本

- 从真实 Ozon 公开页面采集至少 20 个候选。
- 对其中 5 个完成证据充分的深度分析。
- 选择 1–3 个商品进入受控试点。

## 必经流程

公开证据采集 -> 后端校验 -> 评分 -> 人工选择 -> 本地 Listing 草稿 -> 人工确认图片生成 -> 视觉 QA -> 发布快照 -> ActionProposal -> 单独批准 -> Ozon 写入 -> 回读 -> BusinessOutcome。

## 每个候选必须展示

商品图、Ozon 商品链接、标题、价格、评价/评论证据、抓取时间、解析器版本、证据哈希、置信度、评分解释和缺失字段。缺任一关键证据不得显示“建议上架”。

## 放行条件

- 所有高风险动作保持人工审批。
- 调研失败或价格证据不足时阻断草稿和发布。
- 发布载荷必须来自已批准、不可变的 Listing 快照。
- 外部提交使用稳定幂等键并完成回读。

## 当前阻塞

扩展尚未由用户在 Chrome 完成解压安装；没有真实 Ozon 批次、20 个候选、5 个深度分析或 1–3 个商品结果。因此此文档是试点协议，不是通过证明。
